# Robocon 开源 · 个人收集

个人整理的高校 Robocon 开源工程与学习文档目录（非官方）。网站使用 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 本地查看

直接用浏览器打开 `index.html`。

## 部署到 GitHub Pages

将文件推送到 GitHub 仓库。在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，选中实际存放文件的分支（例如 `main`）和 **/ (root)**，保存后使用页面显示的访问地址。

## 更新目录

编辑 `data.js`。每组资料按类别、学校、补充说明、资源列表排列。资源由标题、网址和可选说明组成。网址缺失时留空，页面会显示「待补链接」。分类使用 `2026`、`2027` 或 `docs`。
